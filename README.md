# Topic Modeling with Unsupervised Machine Learning

This repository provides the code and resources for the **Topic Modeling with Unsupervised Machine Learning** section of the main tutorial. It focuses on practical implementations of two common unsupervised machine learning algorithms for topic discovery: **K-Means** and **Latent Dirichlet Allocation (LDA)**.

## Contents and Objectives

The workbooks within this repository are structured to demonstrate key concepts and applications in topic modeling:

* Data Preparation: Methods for extracting and formatting text data from sources like YouTube video transcripts for analysis.
* K-Means for Topic Discovery: Application of K-Means clustering to identify distinct topic clusters and their defining terms.
* LDA for Probabilistic Topic Modeling: Implementation of Latent Dirichlet Allocation for inferring probabilistic topic distributions and understanding word-topic relationships.
* Visualization Techniques: Use of tools like Word Clouds and Gensim's visualization utilities for interpreting topic model outputs.
